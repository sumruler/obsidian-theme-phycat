# Phycat 0.3.4

本次更新保留恢复后的主题外观，补回兼容性与可读性修复，并加入可直接打开的离线配色生成器。

## 更新内容

- 加入离线配色生成器：调整主色、辅助色、背景和文字，自动推导其余颜色；高级颜色可单独修改、锁定并恢复自动计算。
- 亮暗两套独立编辑，支持生成对应模式、加载 12 套预设、导入部分或完整 Style Settings JSON。
- 导出当前模式的 194 项颜色或亮暗合并的 388 项颜色。无效导入会整体取消，保留原有配色。
- 预览直接加载本地主题 CSS，展示笔记阅读、标题、代码、提示框、彩虹文件夹和界面控件；可切换布局、标题样式及自动／手动强调色文字。
- 保留恢复后的标题图标和布局，补回文件图标开关、插件图标优先、链接与复选框作用域、对比度、键盘焦点和减少动态效果修复。
- 完整安装包包含生成器，并将其数据同步、断网打开、下载、导入与窄屏布局纳入项目验证流程。

## 使用与升级

解压完整安装包后，双击 `Phycat/color-generator/index.html` 即可使用。请让整个 `color-generator` 文件夹与 `theme.css` 保持相邻；不需要联网、构建或启动服务。刷新或关闭页面前请导出配色。

生成文件通过 **Style Settings → Import → Import from file** 导入 Obsidian。配色 JSON 只包含颜色；布局、字体、间距及预览选项不写入文件。导入会替换文件中对应的颜色，建议先 Export 保存个人配置。

Obsidian 自动更新器只获取主题核心文件。使用自动更新的用户需要另行下载完整安装包，获取 `color-generator` 文件夹。原生 **外观 → 主题色** 仍优先于预设主色；手动强调色文字需要在 Style Settings 中开启相应选项。

## 安装文件

- `manifest.json` 与 `theme.css`：Obsidian 自动更新使用的核心文件。
- `obsidian-phycat-theme-0.3.4.zip`：完整安装包，含主题、离线配色生成器、12 套预设、说明及许可证。
- `phycat-presets-0.3.4.zip`：独立预设包，通过 Style Settings 导入。
- `SHA256SUMS`：上述文件的 SHA-256 校验值。

最低支持 Obsidian 1.9.0。主题默认配色不依赖插件；自定义与预设导入需要 Style Settings。

English: this update restores the intended theme appearance while retaining compatibility and readability fixes, and adds an offline palette generator. Open `color-generator/index.html` next to `theme.css` to preview the local theme, derive colors from four bases, keep light/dark palettes separate, lock overrides, and import or export Style Settings JSON. The full ZIP includes the generator; the automatic theme updater installs only the core theme files. Export your palette before refreshing or closing the generator.
