# Phycat 0.3.8

修复编辑模式的标题点击定位，适配 Obsidian 1.14 六色高亮，并改进 Callout 原生 SVG 图标兼容。

## 更新内容

- **标题点击定位**：H1–H6 在编辑模式保持完整行宽，上下间距计入标题行布局，装饰不遮挡点击。H2 胶囊编辑时铺满标题行，阅读模式仍保持短胶囊；现有 H1 对齐、字号和间距设置继续生效。
- **六色渐变高亮**：支持 Obsidian 1.14 的红、橙、黄、绿、蓝、紫六色高亮，保留渐变与悬停效果。普通高亮继续跟随主题色，样式限定于笔记文字，保留原生选色菜单和行内色块。
- **Callout 图标兼容**：图标继承标题颜色并保留 SVG 自身的填充方式，继续使用原生图标和类型映射。胶囊标题、右侧水印及折叠功能保持可用。
- **配色生成器预览**：使用真实 SVG 展示各类 Callout 图标，新增六色高亮示例，同步主题版本与颜色数据。
- **回归验证**：增加编辑模式标题行几何、高亮配色隔离与 SVG 填充检查，保留现有配色、图标开关和无障碍兼容检查。

## 升级说明

无需迁移已有 Style Settings 配置或修改笔记内容。六色高亮需要 Obsidian 1.14 或更新版本；旧版 Obsidian 继续支持普通高亮，主题最低版本要求仍为 1.9.0。

Obsidian 自动更新使用独立附件 `manifest.json` 和 `theme.css`。完整安装包为 `obsidian-phycat-theme-0.3.8.zip`，包含配色生成器、预设、说明和许可证；独立预设包为 `phycat-presets-0.3.8.zip`，校验值见 `SHA256SUMS`。

English: fixes full-width editable heading geometry and click targets, adds gradient styling for Obsidian 1.14's six native highlight colors, and preserves native Callout SVG fills and title colors. The offline palette preview now uses real SVG icons and includes six-color highlight examples. Existing Style Settings configurations remain compatible.
