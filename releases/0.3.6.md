# Phycat 0.3.6

更新主题外观与文字悬停效果，同步最新的主题样式。

## 更新内容

- 降低亮暗模式下高亮背景与悬停阴影的强度，使高亮效果更柔和。
- 调整粗体与高亮、斜体组合时的悬停效果，减少重复的文字描边、阴影和下划线，并加粗粗斜体的波浪线。
- 调整主题初始化阶段的显示与过渡效果，设置页面的内容区域改用透明背景。
- 同步标题间距、配色默认值、Style Settings 设置项及文件图标样式的调整。
- 将主题版本和离线配色生成器数据同步至 0.3.6。

## 安装包

Obsidian 自动更新使用 `manifest.json` 和 `theme.css`。完整安装包为 `obsidian-phycat-theme-0.3.6.zip`，独立预设包为 `phycat-presets-0.3.6.zip`，校验值见 `SHA256SUMS`。

English: updates highlight and hover effects, combined bold and italic styling, initialization transitions, settings backgrounds, heading spacing, palette defaults and theme settings. The offline palette generator data is synchronized with version 0.3.6.
