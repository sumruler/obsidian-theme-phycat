# Phycat 0.3.3

本次发布将配色改为独立亮暗调色盘，加入 Everforest、彩虹文件树与编辑模式代码间距设置，并修复发布前检查发现的显示和可读性问题。

## 更新内容

- 12 套 JSON 配色：8 亮色、4 暗色；通过 Style Settings Import 导入并继续调色。
- 文件、文件夹图标独立开关，插件图标优先。
- 修复默认卡片背景、链接文字隐藏、普通复选框样式被覆盖、任务键盘焦点和 Mermaid 选择器。
- 强调色导航和代码文字自动选择黑白；12 套预设代码注释对比度提升至至少 4.5:1。
- 补充减少动态效果和移动端滚动条规则，统一设置默认值、字体行为和中英文说明。

## 升级提醒

从 0.2.x 升级前请 Export 备份 Style Settings。旧配色下拉框不再生效，升级后分别导入对应亮暗 JSON；Ocean 对应 Mint，Cheery 对应 Cherry。原生外观主题色仍优先于预设主色。

已保存自定义颜色的用户：更新不会覆盖你的配置。重新导入预设才能应用新的注释颜色；导入会替换对应模式的调色盘和标题文字颜色，请先备份。

## 安装文件

- `manifest.json` 与 `theme.css`：Obsidian 自动更新使用的核心文件。
- `obsidian-phycat-theme-0.3.3.zip`：完整安装包，含 Phycat 文件夹、预设、说明及许可证。解压放入 `.obsidian/themes/` 后启用。
- `phycat-presets-0.3.3.zip`：独立预设包；自动更新主题后可另行下载，通过 Style Settings Import 导入 JSON。
- `SHA256SUMS`：上述文件的 SHA-256 校验值。

最低 Obsidian 版本为 1.9.0。默认配色无需插件；自定义与预设导入需启用 Style Settings。[霞鹜文楷](https://github.com/lxgw/LxgwWenKai/releases) 是可选推荐字体。

English: separate light/dark palettes and 12 presets, including Everforest. Export settings before upgrading from 0.2.x, then import matching presets. Native accent remains higher priority. This release fixes link visibility, checkbox scope/focus, card defaults and Mermaid styling, improves comment contrast, and respects reduced motion. Download the preset ZIP separately when using Obsidian's automatic theme updater.
