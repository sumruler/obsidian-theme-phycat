# Phycat 0.3.5

修复 0.3.4 中偏离原版外观的暗色卡片外框和任务对勾颜色。

## 更新内容

- 暗色卡片外框保持笔记背景色，移除主色混色，恢复原版深灰外观。背景混色滑块继续作用于亮色外框。
- 任务对勾默认恢复为白色，始终直接使用调色盘中的“复选框对勾”颜色，不再受强调色文字自动黑白逻辑影响。
- 恢复各预设的原版对勾颜色，同步离线配色生成器数据和相关使用说明。
- 增加回归检查，验证暗色卡片背景，以及亮暗模式下普通任务和进行中任务的自定义对勾颜色。

## 升级说明

已有的手动配色保持原值。如果曾导入 0.3.4 的亮色预设，想恢复白色对勾，可在 **Style Settings → 配色设置 → 复选框对勾** 中设置亮色颜色为 `#ffffff`，或重新导入新版对应预设。重新导入完整预设会替换该模式的其他颜色，建议先 Export 保存个人配置。

自动更新只获取 `manifest.json` 和 `theme.css`。离线配色生成器与新版预设请从完整安装包 `obsidian-phycat-theme-0.3.5.zip` 获取；独立预设包为 `phycat-presets-0.3.5.zip`。`SHA256SUMS` 提供核心文件和安装包的校验值。

English: restores the original dark card frame by removing the accent tint, and restores the original task checkmark defaults and preset colors. Checkmarks always use their palette color, independently of automatic accent text contrast. Existing custom colors are preserved; if a 0.3.4 light preset saved black checkmarks, set the light checkmark color to `#ffffff` or import its updated preset. The full ZIP includes the updated offline generator and presets.
