# Phycat 0.3.7

基于经过验证的 0.3.5 主题样式重新发布，修复仓库版本与 GitHub Release 不匹配的问题，并为 Obsidian 社区目录提供完整的新版本发布资产。

## 更新内容

- 保留 0.3.5 的主题样式、预设及兼容性修复。
- 将 manifest、package、依赖锁文件和离线配色生成器数据同步至 0.3.7。
- 提供与版本号完全匹配的 `0.3.7` 发布标签、`manifest.json` 和 `theme.css` 下载文件。
- 完整安装包包含离线配色生成器、预设及使用说明；同时提供独立预设包和 SHA-256 校验文件。
- 更新维护流程：先发布并核验 Release，再更新默认分支的版本，避免主题商店读取到尚无对应 Release 的版本号。

## 升级说明

本次主题样式与 0.3.5 相同。已有的 Style Settings 配置可继续使用。Obsidian 自动更新获取 `manifest.json` 和 `theme.css`；完整安装包为 `obsidian-phycat-theme-0.3.7.zip`，独立预设包为 `phycat-presets-0.3.7.zip`。

如果社区目录尚未识别新版本，可在主题管理页的 **…** 菜单中选择 **Check for new releases**，再选择 **Request review** 请求重新检查。目录的最终审核状态由 Obsidian 管理。

English: republishes the verified 0.3.5 theme styling as 0.3.7 with synchronized version metadata, offline generator data, matching GitHub release assets, complete archives and SHA-256 checksums. The default branch is updated only after the release assets have been verified.
